# Dungeon Crawler Test 2D

A 2D dungeon crawler game developed as an A-level Computer Science class project. This Unity-based game features procedurally generated dungeons, enemy AI, and classic dungeon crawler mechanics.

## 🎮 About The Project

This is a simple 2D dungeon crawler created using Unity. Players navigate through procedurally generated dungeons, battle enemies, and explore various levels. The game features retro-style graphics and 8-bit music to provide a nostalgic gaming experience.

## ✨ Features

- Procedurally generated dungeon levels
- Enemy AI with pathfinding
- Player movement and combat mechanics
- Health and score tracking systems
- Menu and tutorial systems
- Retro 8-bit graphics and music
- Performance monitoring tools

## 🛠️ Built With

- **Unity** - Game Engine (Version 2022.3.9f1)
- **C#** - Programming Language

## 🎯 Getting Started

### Prerequisites

- Unity 2022.3.9f1 or newer
- Basic understanding of Unity Editor

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/AlexSpinks/Alex-S-NEA.git
   ```

2. Open the project in Unity
   - Launch Unity Hub
   - Click "Open" and select the cloned project folder
   - Let Unity import all assets

3. Open the main scene
   - Navigate to `Assets/Scenes/MainMenu.unity`
   - Press Play to start the game

## 🎮 How to Play

1. Start the game from the main menu
2. Use arrow keys or WASD to move your character
3. Navigate through the dungeon
4. Defeat enemies and collect items
5. Try to achieve the highest score!
